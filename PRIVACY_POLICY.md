# Privacy Policy for Vikala Discord Bot

**Last Updated:** June 25, 2026

## 1. Introduction

This Privacy Policy describes how Vikala ("the Bot", "we", "us", or "our") collects, uses, and protects information when you use our Discord bot service. By using Vikala, you agree to the collection and use of information in accordance with this policy.

## 2. Information We Collect

### 2.1 Automatically Collected Data

When you use Vikala in your Discord server, we automatically collect and store:

- **Discord IDs**: User IDs, Server (Guild) IDs, Channel IDs, Role IDs, Message IDs
- **Server Configuration**: Bot settings, enabled features, configured roles and channels
- **Timestamps**: Creation dates, update times, and activity timestamps

### 2.2 User Activity Data

Depending on which features are enabled in your server:

- **Message Content**: For moderation purposes (automod violations, message deletion logs)
- **User Experience**: Level/XP data for leveling systems
- **Moderation Actions**: Cases, warnings, bans, kicks, mutes, and associated reasons
- **Reminders**: User-created reminder content and schedules
- **Verification Data**: Account creation timestamps for age verification
- **Thread Messages**: Content and metadata for modmail/thread systems

### 2.3 External Service Integration Data

- **Google Sheets (VHS Archive)**: Game links, titles, and metadata shared in designated channels are stored in Google Sheets for archival purposes
- **Google API Usage**: We use Google Sheets API with service account authentication for the VHS Archive feature

### 2.4 Data We Do NOT Collect

- Private messages (DMs) between users
- Messages in channels where the bot is not present
- Message content from servers where logging is not enabled
- Personal information beyond Discord-provided data
- Payment information (we do not process payments)

## 3. How We Use Your Information

We use the collected information for:

- **Bot Functionality**: Providing core features like commands, moderation, and automation
- **Server Moderation**: Logging violations, managing cases, and enforcing rules
- **User Experience**: Tracking levels, managing reminders, and personalizing features
- **Archive Management**: Storing game submissions in the VHS Archive system
- **Service Improvement**: Analyzing usage patterns to improve bot features
- **Security**: Detecting and preventing abuse or policy violations

## 4. Google Services Usage

### 4.1 Google Sheets API

The VHS Archive feature uses Google Sheets API to:
- Store game links and metadata in a designated spreadsheet
- Track game information (titles, release dates, status)
- Provide a searchable archive of submitted content

**Google's Privacy Policy**: https://policies.google.com/privacy
**Google API Services User Data Policy**: https://developers.google.com/terms/api-services-user-data-policy

### 4.2 Data Sharing with Google

When using VHS Archive:
- Game URLs and metadata are sent to Google Sheets
- Data is stored in Google's cloud infrastructure
- Access is limited to authorized service accounts
- No personal user data is shared with Google beyond Discord IDs

## 5. Data Storage and Security

### 5.1 Storage Location

- **Database**: MongoDB (self-hosted or cloud-hosted)
- **External Services**: Google Sheets (for VHS Archive only)
- **Backups**: Periodic database backups stored securely

### 5.2 Data Security

We implement security measures including:
- Encrypted connections (TLS/SSL)
- Access controls and authentication
- Regular security updates
- Limited data retention periods
- Service account authentication for Google APIs

### 5.3 Data Retention

- **Active Data**: Retained while the bot is active in your server
- **Moderation Logs**: Retained for server administrator reference
- **User Levels**: Retained while user is active in server
- **Deleted Servers**: Data is automatically removed when bot leaves server
- **User Requests**: Data deleted upon valid user request (see Section 7)

## 7. Your Rights and Choices

### 7.1 Access and Control

Server administrators can:
- View all data stored for their server
- Disable specific features that collect data
- Configure data retention settings
- Remove the bot to delete all server data

### 7.2 Data Deletion

You have the right to request:
- **User Data Deletion**: Contact the bot owner to remove your personal data
- **Server Data Deletion**: Remove the bot from your server (automatic deletion)
- **Specific Data Removal**: Request deletion of specific data categories

### 7.3 Opting Out

- Disable specific features (leveling, logging, automod) to reduce data collection
- Use slash commands instead of message commands to reduce message parsing
- Configure the bot to minimize data retention

### 7.4 Data Portability

Server administrators can request an export of their server's data in JSON format.
